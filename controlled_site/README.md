# Controlled test sites

[dependency_test](dependency_test/README.md) contains the browser fixture used to verify resource collection and dependency relationships. The automated harness can serve the same assets over IPv4 and IPv6 loopback, add controlled single-family URLs, and provide API responses.

Use the [test guide](../tests/README.md) for supported execution commands. The fixture is outside the production dashboard and measurement target list. See the [root README](../README.md) for application setup.
